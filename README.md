## Code-metrics
### Kontext: Statisk analys av källkodsfiler — ett litet CLI-verktyg.

* Som användare vill jag ange en fil och få antalet rader i filen.

* Som användare vill jag få antalet kodrader (exklusive tomma rader och rader med bara enstaka tecken som { eller }).

* Som användare vill jag få ett mått på inbäddad komplexitet (t.ex. maximalt indenteringsdjup eller antal nästlade block).

* Som användare vill jag kunna peka ut en hel katalog och få aggregerad statistik för alla filer.

* (Stretch) Som användare vill jag få en varning om en fil överskrider ett tröskelvärde för komplexitet.
